# Visual review and scoring

Weights: construction 45, topology 25, completeness 15, exterior 10, clarity 5. Allocate each block's points among applicable checks before generation. Empty blocks stay unrated/zero, without shifting evidence points to attractive appearance. All candidates use the same checklist version and content.

Every check contains ID, requirement, maximum points, source IDs, source/figure locator, critical flag and optional partial_rule. In v1.2, construction checks may use applicable manufacturer evidence or explicitly qualified analog reconstruction. Analog agreement never proves this exact model. Exterior/style references cannot establish internal geometry.

## Protocol v2 for new runs

Set `checklist.protocol_version: 2`. Every check adds `node_id`, `aspect`, `essential`, `evidence_level`, `evidence_supported`, and `source_fact`. Read the schemas in [execution.md](execution.md). For each essential functional node, cover applicable `type_count`, `shape`, `attachment`, `placement_connections`, and `material` separately. Exclude an inapplicable aspect with a concrete explanation in `node.excluded_aspects`; missing documentation is a gap, not inapplicability. Nodes are essential by default; mark genuinely secondary detail nodes `essential: false` before generation to avoid requiring every tiny screw's geometry. Checks of essential node aspects cannot be optional. Delivery checks cover exterior, completeness, readability and dry/natural material constraints; required delivery facts should be essential or critical as applicable.

`source_fact` states what the cited page/view actually proves or what it omits. `evidence_supported: true` means it supports this specific fact, not merely that the document applies to the model. A manual listing EPDM does not support the membrane's exact shape or clamping. With missing support set false and review the fact as unknown; the helper refuses pass/partial/fail in place of unknown. A visible feature that conflicts with documented evidence is fail instead. `evidence_level` distinguishes model, series, analog, photo, style, unknown; photo/style cannot prove internal node aspects. Analog pass means agreement with reconstruction, not confirmation of the target model.

Every review records `source_observation`: a concise comparison of the observed feature with the exact applicable source fact. The helper computes evidence basis counts, confirmed facts grouped by model/series/analog, unknown/contradicted/partial facts, unavailable points and a source-supported ceiling. These counts are not percentages of physical accuracy; the ceiling only indicates which checklist points have source support, not what a generation will achieve.

Readiness is separate from selection/rating. An observed critical fail gives `best_available`. Essential fail/partial/unknown, an essential internal fact supported only by analog, or an unrated block gives `needs_technical_review`. Otherwise `ready_for_technical_review`. Every automatic status has `technical_approval: false`. A score of95 or even100 with essential reconstructed geometry still requires technical review. Historical protocol v1 stays readable but cannot acquire full v2 readiness without explicit input update and re-review; its old score is not migrated automatically. v1.2 selection sorts critical contradictions first, then readiness, then technical score; an unconfirmed reconstruction does not outrank a verified candidate merely by its number.

This is an explicit evidence/observation contract, not visual recognition. The agent still decides applicability and observes images; a blind independent evaluator has not been activated. A score-free review packet is available; see [reviewer.md](reviewer.md).

For an explicitly requested evaluator test, compare actual rendered controls to applicable source views before scoring. Record which intended defects actually appeared and incidental regressions. Separate a visual detection trial from a sensitivity calculation that merely changes review flags. Include a false-assessor probe when useful: if erroneous pass observations yield a high score for a clearly defective frame, report the semantic limitation rather than claiming the arithmetic engine detects pixels. Never register that false review as a real candidate assessment. Repeated inspection by the agent who prepared the control is not blind independent validation; label it accordingly.

## Evidence before a number

Prepare checks from the new product's construction map, not by copying the pilot's checklist. Split the mechanism into observable claims about actual shapes, nesting, mating, barriers and physical connections. A smooth disc, closed block or caption may establish visible presence, but cannot establish the concealed working geometry. Unsupported detail remains unknown; a diagram-supported geometry visibly replaced by a placeholder fails that geometry check.

For each important pass record the candidate region and distinguishing feature that matches the cited source view. For a fail record the conflicting feature; for unknown identify what cannot be seen or established. Do not reuse previous observations without looking at the current image. Source text proving a part exists does not prove its rendered shape or attachment. Inspect reference and candidate together at useful scale when possible; preserve the compared views in the evidence archive.

Lead user-facing conclusions with documented matches, observed contradictions and remaining reconstructions. The numeric rating remains an uncalibrated diagnostic, using the v1.2 formula below for new runs. It is not an independent measurement and does not become reliable merely because a script adds the points. Never describe a target of90+ as proof or spend edits to manufacture an increasing score sequence. Do not retroactively rewrite historical ratings without a versioned input update and re-review.

Review the full frame and then important nodes at readable scale. State what is visibly present and where; compare to the source. A caption does not establish the actual part. Do not use the previous rating or the generator's assurance as evidence. `pass`=1; `partial`=.5 only with a predefined noncritical partial_rule; `fail`=0; `unknown`=0 with a reason. Count/type/critical position checks are binary. The script sums points; it does not recognize the mechanism.

For placement checks, distinguish a shared axis from the complete documented assembly: a rotor and stator can be coaxial yet have the wrong radial seating. Inspect the reverse/mating view when available. If a new view reveals an omitted or underspecified fact, explicitly update frozen inputs and re-review candidates; preserve earlier ratings as history and explain the changed criterion. Keep unsupported hidden details unknown rather than replacing them with a familiar mechanism. A selective cut can leave undocumented internals of a valve or impeller closed while exposing the verified functional assembly.

Include exact part geometry/arrangement checks when applicable manufacturer CAD/sections exist. Merely naming a permanent-magnet motor is insufficient if the rotor shape/placement contradicts the factory model. Include the user's dry-master constraint as a critical deliverable check. Water fill/flow arrows in the base fail that check; caption leader lines do not. A separate approved overlay is reviewed separately and cannot earn construction points or make hidden passages verified.

For each functional node inspect shape, assembly placement, material and cut-window choice separately. A large plausible membrane is not enough to establish its exact form or attachment. When an approved image is supplied, distinguish visual similarity from technical approval and manufacturer evidence; list agreements and conflicts. Natural material at cut faces and the absence of contour bands are explicit deliverable checks. Keep weights/checks fixed within a comparison; do not redefine a fact or award unknowns merely to reach a requested 90–95. If missing evidence imposes a score ceiling, explain the missing points and seek better evidence before spending repeated calls on cosmetics.

## v1.2 technical rating and captions

Review JSON covers every ID exactly once. The technical rating is `(construction45 + topology25 + completeness15) / 85 × 100`, using earned points. The denominator stays85 even for unknown or empty blocks. Appearance is separate (`earned appearance / 10 × 100`); captions have checked/needs_correction/not_composed states and no technical points. Original weights within the technical blocks are retained provisionally, not claimed calibrated. Older totals and histories are unchanged and cannot be compared directly to this normalized scale.

Technical checks cannot be caption-dependent. Caption-dependent facts default true in clarity; keep visible dry/natural material constraints caption_dependent:false. First review the base with absent caption checks unknown. Only compose the selected technical90+ candidate, not all qualifying/losing bases. The captioned review must keep every non-caption status identical. If a technical observation changes, submit a separate base reassessment with a concrete reassessment_reason; it preserves the earlier review and clears active caption eligibility until the new base is evaluated. New base/caption reviews are hashed; do not edit saved observations in place.

Readiness and evidence basis remain separate even at100. Analog construction may earn agreement points while still being a reconstruction requiring technical review. A dry-constraint violation is critical even when kept in a separate delivery block, so its critical fail prevents a cosmetic high score from implying readiness.

Critical fail means an observed contradiction against an applicable fact (wrong mechanism, stage count, motor type, important valve position, impossible flow). Critical unknown means not verified; keep it separate. Select candidates with zero critical fails before numeric score. If none qualify, return the best available but explicitly state defects. Even a candidate without critical fails can remain incompletely verified.

Before finalization, re-inspect the leading candidates against facts without consulting earlier ratings when useful; this is self-review unless an authorized separate reviewer actually ran. Same-model repeated passes are not independent expert reviews. If facts change, update inputs explicitly and re-review every existing candidate; stale ratings are invalidated. Don't average unexplained disagreements or force scores to increase.
