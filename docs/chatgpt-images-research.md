# ChatGPT Images: исследование альтернативного способа генерации

13.10.2026. Пользователь выбрал исследование обычного ChatGPT Images ради возможной экономии. Текущий рабочий скилл по-прежнему использует встроенный Codex/imagegen; веб-режим не реализован и не включён автоматически. Новых генераций в этом исследовании0.

## Что подтверждено официальной документацией

[Генерация изображений](https://learn.chatgpt.com/docs/image-generation) и [учёт расхода](https://learn.chatgpt.com/docs/pricing#how-does-image-generation-count-toward-usage-limits) прямо указывают, что встроенная генерация в Codex расходует общий лимит. В среднем такие ходы расходуют его в3–5 раз быстрее похожих ходов без генерации, в зависимости от размера/качества. Это не процент за PNG и не обход лимита через имя инструмента imagegen.

В ChatGPT web доступность изображений и лимиты зависят от тарифа/настроек workspace. Утверждение пользователя о привычном малом расходе ещё не измерено в сопоставимом пилоте. [ChatGPT Work](https://learn.chatgpt.com/docs/use-chatgpt#what-chatgpt-work-can-do) делит лимиты с Codex: переключение в Work не подтверждает экономию. Изучается обычный Chat/Images. Через Image API применяется отдельная API-оплата, а не бесплатное программное использование подписки.

## Что проверено в интерфейсе

- Во встроенном браузере открыта отдельная скрытая вкладка https://chatgpt.com/.
- На фактически загруженной странице видны обычный чат, раздел Images, кнопки входа и сообщение о необходимости войти для создания изображений/загрузки файлов.
- Страница объявляет WebMCP-инструменты для состояния чата, моделей, черновика, загрузки файлов, отправки сообщения и отслеживания завершения. Их наличие наблюдалось в метаданных страницы; создание изображений через них не испытано.
- Эта браузерная сессия не авторизована. Никаких сообщений/фотографий не отправлено, изображения не генерировались. Полный цикл загрузки/генерации/редактирования/скачивания и экономия не подтверждены.

Первоначальная попытка проверить Chrome прервалась при изменении приложения; переход не был подтверждён, повторная проверка выявила другую активную страницу. Дальше использован отдельный встроенный браузер. Его начальная навигация превысила ожидание, но список вкладок и видимая страница затем подтвердили успешную загрузку. Один вызов получения таба вернул ошибку привязки переменной после неудачной навигации; состояние самой страницы всё же отобразилось. Эти ошибки не означают недоступность ChatGPT Images после входа.

## Предлагаемый веб-процесс после пилота

1. Точная карточка477477.ru, исходное фото, заводские источники и фиксированный checklist остаются в агенте.
2. Для товара открывается отдельный обычный ChatGPT-чат в авторизованном управляемом браузере. Сохраняется его связь с локальным запуском; чужой текущий чат/черновик не переиспользуются.
3. Агент загружает сохранённые публичные референсы и отправляет подготовленный промпт через обычный интерфейс/объявленные инструменты страницы. Номер попытки, промпт и референсы записываются до отправки.
4. Отправленный запрос не считается завершённым. Агент наблюдает состояние и сохраняет фактическое созданное изображение доступным способом скачивания, затем проверяет файл. При неизвестном результате не отправляет повторный запрос автоматически.
5. Оценка идёт по тем же заводским фактам; текстовые уверения генератора не являются доказательством. Исправления возвращаются в тот же товарный чат. Максимум5 попыток и история сохраняются.
6. При оценке базы80+ подписи создаются локальной программой и сразу показываются в текущем чате. В конце выбирается один главный PNG; остальные сохраняются.

Это проект адаптера, не готовая функция. Загрузка/получение файлов, сохранение состояния, возобновление и применимые лимиты нуждаются в реальном испытании после входа. Не объявлять функции отправки/скачивания проверенными только по описанию WebMCP. Не подменять UI неофициальными скрытыми запросами или переносом сессии из другого браузера.

## Как проверять экономию

Минимальный будущий пилот — одна генерация и одна редактура одного товара с одинаковыми источниками и критериями. Сначала нужен выполненный вход в обычный ChatGPT в доступном агенту браузере. После этого проверяются реальный результат, скачивание, история и повторное открытие. Текущий этап не расходует генерации ради измерения.

Фиксировать отдельно: число генераций, обычные лимиты ChatGPT Images если интерфейс их показывает, изменение пятичасового лимита Codex, время и число управляющих действий. Поиск источников, управление браузером и визуальная оценка агентом всё равно расходуют ресурсы Codex. Общая разность лимитов аккаунта не относится к одному товару при других активных задачах или смене окна. Без контролируемого сравнения не обещать ни нулевой расход, ни конкретный процент экономии.
