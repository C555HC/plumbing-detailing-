# Запуск v0.1

## Через Codex

Скилл хранится в [.agents/skills/product-cutaway-agent](../.agents/skills/product-cutaway-agent/SKILL.md). На компьютере пилота также создана ссылка `~/.codex/skills/product-cutaway-agent` на эту папку; исходники остаются в репозитории. Файл по локальной ссылке прошёл структурную проверку. Обнаружение новым отдельным чатом ещё не проверялось.

Пример запроса:

```text
$product-cutaway-agent Сделай учебный разрез товара https://477477.ru/catalog/nasosy/aquario-2700. Сохрани все варианты и отчёт. Максимум 5 генераций.
```

Если скилл ещё не появился в доступных навыках текущей задачи, можно явно указать полный путь к его SKILL.md и попросить выполнить инструкции. Агенту нужны доступные поиск, просмотр файлов/изображений и встроенный imagegen. Помощники не вызывают модель напрямую и не работают как самостоятельный генератор.

Для продолжения укажите папку запуска и правку:

```text
Продолжи сохранённый запуск AQUARIO в pilot/aquario-joker1-100vs/20261009T223138Z-3c5a9d39. Используй вариант 6; измени подпись гидроаккумулятора, сохрани старую версию.
```

Исторические пилоты с лимитом10 сохранены. Новые запуски используют максимум5 и протокол оценки v2. Пересборка подписей не требует генерации. Техническая правка требует повторной проверки; явный запрос продолжить после выдачи открывает связанный раунд до5 без сброса прежней истории.

## Среда и проверки помощников

Python 3.10+; macOS/Linux. Виртуальная среда пилота `.venv` использует комплектный Python Codex. На другом компьютере можно создать обычную среду:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m unittest discover -s tests -v
```

Рабочая зависимость — Pillow; PyYAML нужен для валидатора упаковки скилла. Для русских подписей требуется доступный TrueType-шрифт с кириллицей; поддерживается `--font`. PDF можно читать и рендерить доступными средствами агента: PDF-библиотека не является обязательной зависимостью механики запуска.

Команды помощников и формы JSON: [execution.md](../.agents/skills/product-cutaway-agent/references/execution.md). По умолчанию новые результаты создаются в отдельной output-папке и не коммитятся автоматически. Пилот в `pilot/` опубликован намеренно по запросу пользователя. Полные скачанные PDF/HTML и кэш заводских страниц остаются локальными; URLs и применимость источников доступны в sources.json и отчёте.
