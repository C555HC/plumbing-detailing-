# Работы над первой версией

Начало: 10 октября 2026 года. Пилот: AQUARIO Joker1-100VS, артикул магазина 2700. Этот журнал хранит фактические ошибки, исправления, результаты и открытые ограничения; не заменяет историю Git или оценки изображений.

## Исходные условия

- Пользователь разрешил сборку, самостоятельное исправление ошибок проекта и коммиты прямо в main.
- Для пилота сохраняется максимум 10 вызовов генератора/редактора. Разрешение работать ночью не меняет этот отдельный лимит.
- Реализация собственная. fal-workflow, PaperVizAgent и fal-skill-creator используются как заменяемые источники идей, без установки их пакетов.
- Предпочтительный исполнитель — встроенный imagegen в активной задаче Codex. Самостоятельная фоновая очередь и API-исполнитель в v0.1 не входят.

## Сборка и первая проверка механики

- Созданы SKILL.md, справочники и два помощника: состояние/рейтинг/отчёт, программная сборка подписей в PNG. Внешние API не подключались.
- Первые 30 unit/integration-проверок прошли локально. Проверяют реальные файловые операции и подготовленные оценки, но не распознавание конструктивных ошибок на сгенерированных картинках.
- При проверке кода обнаружен риск: проверялся хеш checklist, но изменения spec/sources перед финализацией могли остаться незамеченными. Исправление: хеши всех трёх входных файлов, проверка перед генерацией/review/итогом, проверка неизменности всех сравниваемых PNG. Добавлены три регрессионных теста.
- Первая попытка применения этого патча отклонена из-за порядка контекстов; файлы не изменились. Патч переставлен по порядку строк и применён повторно.
- Заводской каталог DAB по ссылке с www вернул HTTP 404. Веб-инструмент получил 403 для альтернативной страницы DAB и 503 для каталога Grundfos. Проверяются прямое получение и доступные официальные ссылки; это не трактуется как отсутствие документации.
- Локальный Poppler успешно отрисовал нужные страницы AQUARIO; схема и таблица визуально проверены. Обход ошибки веб-скриншотов подтверждён.
