# Работы над первой версией

Начало: 10 октября 2026 года. Пилот: AQUARIO Joker1-100VS, артикул магазина 2700. Этот журнал хранит фактические ошибки, исправления, результаты и открытые ограничения; не заменяет историю Git или оценки изображений.

## Исходные условия

- Пользователь разрешил сборку, самостоятельное исправление ошибок проекта и коммиты прямо в main.
- Для пилота сохраняется максимум 10 вызовов генератора/редактора. Разрешение работать ночью не меняет этот отдельный лимит.
- Реализация собственная. fal-workflow, PaperVizAgent и fal-skill-creator используются как заменяемые источники идей, без установки их пакетов.
- Предпочтительный исполнитель — встроенный imagegen в активной задаче Codex. Самостоятельная фоновая очередь и API-исполнитель в v0.1 не входят.

## Сборка и первая проверка механики

- Созданы SKILL.md, справочники и два помощника: состояние/рейтинг/отчёт, программная сборка подписей в PNG. Внешние API не подключались.
- Первые 30 unit/integration-проверок прошли локально. Проверяют реальные файловые операции и подготовленные оценки, но не распознавание конструктивных ошибок на сгенерированных картинках.
- При проверке кода обнаружен риск: проверялся хеш checklist, но изменения spec/sources перед финализацией могли остаться незамеченными. Исправление: хеши всех трёх входных файлов, проверка перед генерацией/review/итогом, проверка неизменности всех сравниваемых PNG. Добавлены три регрессионных теста.
- Первая попытка применения этого патча отклонена из-за порядка контекстов; файлы не изменились. Патч переставлен по порядку строк и применён повторно.
- Заводской каталог DAB по ссылке с www вернул HTTP 404. Веб-инструмент получил 403 для альтернативной страницы DAB и 503 для каталога Grundfos. Проверяются прямое получение и доступные официальные ссылки; это не трактуется как отсутствие документации.
- Локальный Poppler успешно отрисовал нужные страницы AQUARIO; схема и таблица визуально проверены. Обход ошибки веб-скриншотов подтверждён.

## Реальный пилот и исправления

- Первые 33 проверки прошли и локально, и в GitHub Actions. Структурный валидатор skill-creator также прошёл. Это не независимая инженерная экспертиза.
- Для аналога успешно получены инструкция ESPA TECNOPLUS (схема стр.67) и Caleffi 01079/01 (принцип мембраны стр.2). Прямые попытки других адресов DAB/Grundfos завершились 404/403; их содержимое не использовано. Материалы и количество ступеней аналогов не перенесены.
- Poppler при рендере ESPA выдал предупреждение Fontconfig. PNG создан, русские/латинские подписи и схема осмотрены: для выбранной страницы результат пригоден. Системный Fontconfig не менялся.
- Генератор не оставил запрошенные широкие поля. Исправлено без новой генерации: compose_png умеет отдельный белый холст и область размещения базового PNG. Исходное изображение не перезаписывается.
- Первичная выноска уплотнения попала на соседнюю область двигателя. Точка скорректирована и PNG пересобран до первой оценки.
- Попытка обновить JSON патчем с удалением/созданием одного пути отклонена инструментом. JSON исправлен обычной записью; повторная генерация не потребовалась.
- На широком варианте №5 повторное использование координат квадратного кадра поставило часть точек мимо узлов. Первичная оценка выносок была слишком уверенной. Исправлено: координаты target_image задаются относительно исходного PNG, учитываются масштаб и поля; фактические границы размещения сохраняются. Добавлены регрессионные тесты. Выноски №5 пересобраны и осмотрены без новой генерации; старая версия сохранена для истории.
- В одном новом тесте появилось ResourceWarning о незакрытом PNG. Файл открывается через контекстный менеджер; предупреждение устранено.
- Повторный осмотр снизил оценки №3/4: канал ниппеля у горизонтальной мембраны оказался неоднозначным. История оценок сохранена, а не переписана задним числом. №6 использует другой изгиб мембраны и яснее отделяет газовый канал.

## Открытые ограничения v0.1

- Непрерывную последовательную связь возвратных каналов не удалось убедительно проверить после нескольких способов раскрытия. Не начислены 8 баллов T1; лучший вариант не получает статус полностью технически проверенного. Для следующего улучшения нужен внутренний разрез/деталировка этой модели либо оценка специалиста.
- Первичные визуальные оценки оказались нестабильны; веса не менялись, но трактовка наблюдений потребовала повторной проверки. Калибровка специалистом ещё не проведена.
- Форма мембраны, клапана, каналов и элементов двигателя не подтверждена точной внутренней заводской схемой. Источники аналогов и границы их использования раскрыты в отчёте.
- Скрипт контролирует выдачу попыток, но не перехватывает произвольные прямые вызовы встроенного инструмента: агент должен соблюдать протокол.
- Сервис автономной очереди, перенос на Windows и независимые реальные генерации в нескольких чатах не проверены. Файловая изоляция и блокировки проверяются автоматическими тестами.
- Точный расход токенов инструмент не предоставил; проценты экономии не заявляются. Спецификация и источники использовались повторно, а история сохранялась в файлах.
- Страница магазина остаётся недоступной для автоматического получения; пилот использовал предоставленное фото.
